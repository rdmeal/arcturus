# wait-what

Type it when Claude's last message didn't land. Claude says it again, more simply: a sentence or two of context, then the point, in short plain sentences (ASD-STE100 Simplified Technical English) and using the glossary's terms instead of jargon. If the message asked you something, the question comes again at the end.

## How to use it

| You type                             | Claude re-pitches               |
| ------------------------------------ | ------------------------------- |
| `/wait-what`                         | the whole of its last message   |
| `/wait-what the bit about seats`     | just that part                  |

It works anywhere, in any conversation, including in the middle of a grilling session. It adds nothing new; it only makes the last message easier to follow.
